# 雑学クイズ

本当か嘘か、知識で見破れ。〇×形式の雑学クイズサイト。

**公開URL：** https://otani-png.github.io/trivia-quiz/

## 特徴

- 〇×の二択で答えるシンプルなクイズ（全43問・エンドレス出題）
- 回答すると「みんなが〇と×をどのくらいの割合で選んだか」が%で表示される
- 通算成績（正解数・挑戦数・正解率）はブラウザに保存され、閉じても消えない

## 仕組み

| データ | 保存場所 |
|---|---|
| みんなの回答数（全ユーザー共通） | Firebase Realtime Database |
| 自分の通算成績 | ブラウザの localStorage |

ファイルは `index.html` の1枚だけ。HTML/CSS/JS をすべてこの中に書く（詳しくは `CLAUDE.md`）。

## Firebase セットアップ（初回のみ）

1. [Firebase コンソール](https://console.firebase.google.com/) で新規プロジェクトを作成
   - **プロジェクトIDを `trivia-quiz-otani` にする**（IDが違うと接続できない。変えた場合は `index.html` の `FIREBASE_CANDIDATES` を書き換える）
2. 左メニュー「構築」→「Realtime Database」→「データベースを作成」
   - ロケーションはどこでもOK（コードが自動でリージョンを探す）
   - ルールは「テストモード」で開始してよい
3. **重要：** 「ルール」タブを開き、この リポジトリの `database.rules.json` の中身を貼り付けて「公開」する
   - テストモードのルールは約1ヶ月で期限切れになり、その後は投票が記録されなくなる
   - このルールを入れると「読み取りは誰でも / 書き込みは1票ずつの加算のみ」になり、票の改ざんや消去を防げる

## 投票データの構造

```
votes/
  0: { t: 〇と答えた人数, f: ×と答えた人数 }
  1: { t: ..., f: ... }
  ...（問題idごと）
```

- 票の加算はサーバー側の `increment` で行うので、同時に複数人が答えてもズレない
- Firebase に接続できない場合、%表示だけが静かに消える（クイズ自体は普通に遊べる）

## ローカルで動かす

ブラウザで `index.html` を直接開くだけでも動く。ローカルサーバーを使う場合：

```
python -m http.server 3333
```

→ http://localhost:3333 を開く。

## テスト

```
node test.js
```

ブラウザなしで index.html 内のJSを動かし、投票の送信・%表示・リージョン自動検出・オフライン時の挙動・問題データの整合性を確認する。
